============================
  ȘtiriIO - Ghid de pornire
============================

CERINȚE:
  - Node.js instalat (descarcă de la https://nodejs.org)

PORNIRE (Mac / Linux):
  1. Deschide Terminalul
  2. Navighează în folderul aplicației:
     cd calea/catre/stirio
  3. Rulează serverul:
     node server.js
  4. Deschide browserul la adresa:
     http://localhost:3000

PORNIRE (Windows):
  1. Dublu-click pe fișierul: start.bat
  2. Deschide browserul la adresa:
     http://localhost:3000

OPRIRE:
  Apasă Ctrl+C în terminal.
